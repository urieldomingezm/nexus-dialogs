Por quê

Os alertas resolvem o «Tem certeza?» e pouco mais. O nexus-dialogs traz também formulários com validação, assistentes de vários passos, importar e exportar Excel, validadores do México e modelos de RH.

Camada superior real

Sem guerras de z-index com Bootstrap, outras bibliotecas ou seu menu fixo. O fundo fica inerte e a rolagem bloqueada.

Shadow DOM

O CSS da sua página não o quebra e o dele não vaza. Funciona com uma CSP estrita, sem unsafe-inline.

Promessas que não falham

const r = await dialog.confirm(…) sempre resolve com { confirmed, denied, value, reason }.

Acessível de verdade

Foco inicial correto, Esc, retorno do foco, erros ligados a cada campo, toasts anunciados e movimento reduzido. Testado com axe.

Feito para RH e contabilidade

RFC, CURP, NSS e CLABE com dígito verificador, valores em pesos, dias úteis e feriados, assinatura, endereço por código postal.

Em uma linha

Cada receita já traz o texto, os botões, o foco e a acessibilidade corretos.

import { dialog } from 'nexus-dialogs'
import { confirmDelete } from 'nexus-dialogs/patterns'
import { form } from 'nexus-dialogs/forms'
import { toast } from 'nexus-dialogs/toast'

if (await confirmDelete({ what: 'Laura Méndez' })) await api.funcionarios.excluir(id)

const r = await form({
  title: 'Nova despesa',
  fields: [
    { name: 'rfc', label: 'RFC do fornecedor', type: 'rfc', required: true },
    { name: 'valor', label: 'Valor', type: 'money', required: true },
  ],
})
if (r.confirmed) toast.success('Enviado para aprovação')
