Pruébalo aquí mismo

Estos botones usan la librería de esta página, no capturas.

Por qué

Las alertas resuelven el «¿Seguro?» y poco más. nexus-dialogs trae además formularios con validación, asistentes de varios pasos, importar y exportar Excel, validadores de México y plantillas de RR. HH.

Capa superior real

Sin guerras de z-index con Bootstrap, otras librerías o tu menú fijo. El fondo queda inerte y el scroll bloqueado.

Shadow DOM

El CSS de tu página no lo rompe y el suyo no se sale. Funciona con una CSP estricta, sin unsafe-inline.

Promesas que no fallan

const r = await dialog.confirm(…) siempre resuelve con { confirmed, denied, value, reason }.

Accesible de verdad

Foco inicial correcto, Esc, regreso del foco, errores ligados a cada campo, toasts anunciados y movimiento reducido. Probado con axe.

Hecho para RR. HH. y contabilidad

RFC, CURP, NSS y CLABE con dígito verificador, importes en pesos, días hábiles y festivos, firma, domicilio por código postal.

Migra desde SweetAlert2

En una línea

Cada receta ya trae el texto, los botones, el foco y la accesibilidad correctos.

import { dialog } from 'nexus-dialogs'
import { confirmDelete } from 'nexus-dialogs/patterns'
import { form } from 'nexus-dialogs/forms'
import { toast } from 'nexus-dialogs/toast'

if (await confirmDelete({ what: 'a Laura Méndez' })) await api.empleados.borrar(id)

const r = await form({
  title: 'Nuevo gasto',
  fields: [
    { name: 'rfc', label: 'RFC del proveedor', type: 'rfc', required: true },
    { name: 'importe', label: 'Importe', type: 'money', required: true },
  ],
})
if (r.confirmed) toast.success('Enviado a aprobación')
