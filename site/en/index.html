Why

Alerts solve the “Are you sure?” and little else. nexus-dialogs also brings forms with validation, multi-step wizards, Excel import and export, Mexican validators and HR templates.

A real top layer

No z-index wars with Bootstrap, other libraries or your sticky menu. The background becomes inert and scrolling is locked.

Shadow DOM

Your page’s CSS doesn’t break it and its own doesn’t leak out. It works with a strict CSP, without unsafe-inline.

Promises that don’t fail

const r = await dialog.confirm(…) always resolves with { confirmed, denied, value, reason }.

Truly accessible

Correct initial focus, Esc, focus return, errors tied to each field, announced toasts and reduced motion. Tested with axe.

Made for HR and accounting

RFC, CURP, NSS and CLABE with check digit, amounts in pesos, business days and holidays, signature, address by postal code.

Migrate from SweetAlert2

Change the import and your code keeps working. See how to migrate.

In one line

Each recipe already comes with the right text, buttons, focus and accessibility.

import { dialog } from 'nexus-dialogs'
import { confirmDelete } from 'nexus-dialogs/patterns'
import { form } from 'nexus-dialogs/forms'
import { toast } from 'nexus-dialogs/toast'

if (await confirmDelete({ what: 'Laura Méndez' })) await api.employees.remove(id)

const r = await form({
  title: 'New expense',
  fields: [
    { name: 'rfc', label: 'Supplier RFC', type: 'rfc', required: true },
    { name: 'amount', label: 'Amount', type: 'money', required: true },
  ],
})
if (r.confirmed) toast.success('Sent for approval')
