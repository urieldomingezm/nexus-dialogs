Pourquoi

Les alertes règlent le « Êtes-vous sûr ? » et peu d’autre chose. nexus-dialogs apporte aussi des formulaires avec validation, des assistants en plusieurs étapes, l’import et l’export Excel, des validateurs mexicains et des modèles RH.

Vraie couche supérieure

Pas de guerres de z-index avec Bootstrap, d’autres bibliothèques ou votre menu fixe. L’arrière-plan devient inerte et le défilement est bloqué.

Shadow DOM

Le CSS de votre page ne le casse pas et le sien ne déborde pas. Fonctionne avec une CSP stricte, sans unsafe-inline.

Des promesses qui n’échouent pas

const r = await dialog.confirm(…) se résout toujours avec { confirmed, denied, value, reason }.

Vraiment accessible

Bon focus initial, Échap, retour du focus, erreurs liées à chaque champ, toasts annoncés et mouvement réduit. Testé avec axe.

Conçu pour les RH et la comptabilité

RFC, CURP, NSS et CLABE avec chiffre de contrôle, montants en pesos, jours ouvrés et fériés, signature, adresse par code postal.

En une ligne

Chaque recette apporte déjà le bon texte, les bons boutons, le bon focus et la bonne accessibilité.

import { dialog } from 'nexus-dialogs'
import { confirmDelete } from 'nexus-dialogs/patterns'
import { form } from 'nexus-dialogs/forms'
import { toast } from 'nexus-dialogs/toast'

if (await confirmDelete({ what: 'Laura Méndez' })) await api.employes.supprimer(id)

const r = await form({
  title: 'Nouvelle dépense',
  fields: [
    { name: 'rfc', label: 'RFC du fournisseur', type: 'rfc', required: true },
    { name: 'montant', label: 'Montant', type: 'money', required: true },
  ],
})
if (r.confirmed) toast.success('Envoyé pour approbation')
